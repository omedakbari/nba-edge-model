# Prospective closing collection

The user LaunchAgent polls every 60 seconds; captures occur only for scheduled games in the last ten minutes before tipoff, with HTTP freshness evidence and the same bookmaker as the saved pick. No forecasts are generated by this job. It exits nonzero and archives the failure if sources are unavailable. It does not wake a sleeping Mac; keep the machine awake and network-connected during games.

Install and activate (no administrator access):

```sh
cd /Users/omedakbari/projects/nba-edge-model
./venv/bin/python scripts/install_closing_launchd.py --activate
launchctl print gui/$(id -u)/com.omedakbari.nba-closing
./venv/bin/python scripts/capture_closing_odds.py --window-minutes 10
tail -n 30 logs/closing_capture.log
tail -n 30 logs/closing_capture.error.log
./venv/bin/python scripts/report_clv.py
```

The job skips non-window games, including empty slates. Inspect `data/closing_snapshots/YYYY-MM-DD/` for successful runs, source failures, excluded records, book identity, HTTP Date, capture/start times and freshness. `ok=true` with zero observations means the process worked but no verified same-book observation qualified; it is not proof that closing lines were collected. CLV remains a research measurement with no betting approval.

Stop the collector:

```sh
launchctl bootout gui/$(id -u)/com.omedakbari.nba-closing
```
